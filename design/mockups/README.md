# Open Tutor mockups

The [selected second-pass gallery](pass-2/README.md) records the agreed visual direction: the blue companion without wings, looking toward the learner or inward toward the board, with more space for teaching.

These are generated PNG concepts, not a running application. The [PRD](../../PRD.md) describes behaviour and the [style guide](../STYLE-GUIDE.md) describes visual rules.

The gallery contains ten screen states and a character sheet. Exact image-generation prompts and the intermediate renders needed to explain corrections are kept with the selected set. Earlier explorations remain local working material.
