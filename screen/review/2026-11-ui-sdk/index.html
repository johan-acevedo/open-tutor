Smart Screen exercise comparison

Six fictional Swedish homework tasks at 370 × 610 CSS pixels. The screen model and lesson request are the same in each pair. The second arm receives a catalogue of four new exercise components.

Four of six exercises were clearer with the new blocks. Ordering and matching benefited most. Keep testing the blocks before adopting the SDK dependency.

The prototype inlines a 223,793-byte UI SDK bundle into experiment frames (79,656 bytes gzip). The web app entry chunk grew by 245,670 raw bytes and 84,020 gzip bytes.
